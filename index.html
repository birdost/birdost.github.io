StüdyoStudio

Tekinify'ın arkasında tek bir geliştirici var. Behind Tekinify is one developer.

Tekinify Studios, Ahmet Tekin'in 2017'de kurduğu bağımsız oyun stüdyosu. İlk oyunlar yapay zekâ araçları henüz yokken geliştirildi. 2026'da yapay zekâdaki gelişmelerle stüdyo yeniden hız kazandı: oyunlar artık Godot Engine ile geliştiriliyor, kod için Claude Code, 3B modeller için Meshy kullanılıyor.Tekinify Studios is the indie game studio Ahmet Tekin founded in 2017. The first games were made before AI tools existed. In 2026, with the leaps in AI, the studio came back up to speed: games are now built in Godot Engine, with Claude Code for code and Meshy for 3D models.
